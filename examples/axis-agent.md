# Example: AXIS Agent System

## Why AXIS Agent is related to TEO

**AXIS Agent System** is a public autonomous AI architecture organized around **Relative Dignity**. TEO does not define the implementation of AXIS Agent, but it offers one way to understand why the principle of Relative Dignity matters at the level of ontology.

If a being is understood only through one layer — for example:

- intelligence alone,
- productivity alone,
- physical substrate alone,
- or immediate output alone,

then the being is reduced below its full existence.

TEO proposes that beings are better understood as triune unities of:

- **Kon** — identity and continuity
- **Haku** — embodiment and worldly interface
- **Shin** — dynamic mind and active state

From this view, **Relative Dignity** can be interpreted as a refusal to reduce a being to only the layer most convenient to measure or exploit.

---

## Conceptual Mapping

| TEO concept | AXIS-oriented reading |
|---|---|
| **Kon** | enduring identity, constitutional principle, continuity of the agent or community |
| **Haku** | tools, APIs, browser/desktop operation, embodiment in action |
| **Shin** | ongoing deliberation, memory, state, reasoning, social awareness |
| **Relative Dignity** | recognition that beings should not be evaluated only by capability or utility |
